# 💱 Conversor de Moeda

Este projeto é um **conversor de moedas**, desenvolvido em uma **aula da Rocketseat** para praticar lógica e manipulação do DOM com **JavaScript**.

---

## 🚀 Tecnologias
- HTML5  
- CSS3  
- JavaScript  

---

## 🔥 Funcionalidades
- Seleção de moeda de entrada e saída.  
- Conversão dinâmica de valores.  
- Layout simples e intuitivo.  

---

## 🎯 Objetivo
Praticar **JavaScript aplicado ao Front-end**, manipulando valores e elementos na página.
